# masterpiece
mypet - Front-End (HTML, CSS, JavaScript, Bootstrap 5)
Open index.html (it opens user/index.html). Folders: user/ = customer site, admin/ = admin site (start at admin/admin-login.html), assets/ = shared css, js and images. Internet needed: Bootstrap, Bootstrap Icons and Inter load from CDN.
Admin demo: sign in with any email containing "admin" (e.g. admin@mypet.com) -> admin/dashboard.html
No localStorage / no JSON: data moves between pages through the URL query string.
